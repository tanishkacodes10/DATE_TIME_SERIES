# Date and Time Series Assignment

## 📌 About
This repository contains my Date and Time Series assignment as part of the **Data Science and Visualization (DSV)** subject.

Date and Time Series analysis involves working with dates, times, timestamps, and time-based data. Python provides the `datetime` and `pandas` libraries to handle and analyze date and time information efficiently.

## 🎯 Objectives
- Understand date and time concepts in Python.
- Create and manipulate datetime objects.
- Extract year, month, day, hour, and minute.
- Convert strings into datetime objects.
- Perform date and time arithmetic.
- Calculate time differences.
- Work with time series data using Pandas.

## 🛠️ Tools & Technologies
- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Datetime Module

## 📚 Topics Covered
1. Introduction to Date and Time
2. Creating Datetime Objects
3. Extracting Date and Time Components
4. String to Datetime Conversion (`strptime`)
5. Datetime Formatting (`strftime`)
6. Date and Time Arithmetic
7. Calculating Time Differences
8. Working with Time Series Data
9. Pandas Date and Time Functions

## 📂 Repository Contents
- `Date_Time_Series.ipynb` – Jupyter Notebook containing practical implementation of date and time operations.
- `README.md` – Assignment description and documentation.
